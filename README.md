# Northstar Studio — Business Landing Page

A polished, responsive business landing page made with vanilla HTML, CSS, and JavaScript.

> Northstar Studio is a fictional demo brand. Replace its name, copy, services, and contact details with your own business information before publishing.

## Features
- Responsive hero section and call-to-action
- About, services, approach, process, and contact sections
- Mobile navigation with accessible state
- Custom CSS artwork and responsive layouts
- No frameworks, build step, or external JavaScript dependencies

## Run locally
Open `index.html` directly, or run `python3 -m http.server 8000` and visit http://localhost:8000.

## Customize
- Search for “Northstar” in `index.html` and replace the demo brand.
- Update service descriptions and process steps.
- Replace `hello@example.com` with your business email.
- Adjust colors in the `:root` block in `style.css`.

## Deploy
Enable GitHub Pages in **Settings → Pages**, select **Deploy from a branch**, then choose **main** and **/(root)**.
